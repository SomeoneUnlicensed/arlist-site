# Политика конфиденциальности сервиса Geotekt

**Редакция 1.0 от 17.03.2026**

Используя Платформу, вы подтверждаете, что ознакомились с условиями настоящей Политики конфиденциальности и принимаете их в полном объеме.

## 1. Собираемые данные
1.1. **Данные, предоставляемые Пользователем:**
● Регистрационные данные (имя, адрес электронной почты, логин).
● Контент, размещаемый Пользователем (репозитории, комментарии, файлы, изображения).
1.2. **Данные, собираемые автоматически:**
● Технические данные (IP-адрес, тип браузера, операционная система, реферер).
● Данные статистики посещений (файлы cookie, идентификаторы устройств).
1.3. **Обработка биометрических данных:** Платформа не осуществляет сбор и обработку биометрических данных для идентификации личности, за исключением случаев, прямо предусмотренных функционалом отдельных сервисов и при получении отдельного согласия Пользователя.

## 2. Цели обработки данных
Оператор собирает и обрабатывает данные исключительно в следующих целях:
2.1. Идентификация Пользователя для обеспечения доступа к функциям Платформы.
2.2. Обеспечение работы Платформы, включая хостинг кода и совместную работу над проектами.
2.3. Улучшение качества сервиса, анализ пользовательского опыта и исправление ошибок.
2.4. Коммуникация с Пользователем (отправка уведомлений о событиях, изменениях в работе сервиса).
2.5. Обеспечение безопасности и предотвращение мошеннических действий.

## 3. Передача данных третьим лицам
3.1. Оператор **не продает** персональные данные Пользователей.
3.2. Передача данных третьим лицам допускается только в случаях:
● Обработка данных (хостинг, аналитика).
● Законные требования (раскрытие строго в соответствии с законодательством РФ).
● Защита прав Оператора или третьих лиц.

## 4. Права Пользователя
4.1. **Право на доступ:** Вы можете запросить информацию о своих данных.
4.2. **Право на уточнение:** Вы можете требовать изменения или дополнения данных.
4.3. **Право на удаление:** Вы можете инициировать удаление учетной записи через интерфейс Платформы.
4.4. **Отзыв согласия:** Вы можете отозвать согласие на обработку персональных данных.

## 5. Файлы cookie (Cookies)
Платформа использует файлы cookie для обеспечения работы и сбора статистики. Вы можете настроить отключение cookie в настройках браузера.
